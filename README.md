# Findex Lab 01

Проєкт для порівняння потокової та жадібної обробки текстів.

## Вимірювання

| Версія | Час (с) | Пікова пам'ять (MB) | Документів | Токенів |
|--------|---------|---------------------|------------|---------|
| Потокова | 4.6683 | 10.36 | 3 | 1170000 |
| Жадібна | 4.0089 | 68.59 | 3 | 1170000 |

### Куди пішла пам'ять у жадібній версії

Жадібна версія зберігає в пам'яті:
1. **Список усіх документів** (`documents`): сумарний розмір усіх текстів (близько 8 МБ) у пам'яті.
2. **Список усіх токенів** (`all_tokens`): кожен токен — це окремий об'єкт `str` у Python, що створює значні накладні витрати (заголовок об'єкта, вказівники тощо). Для 1.17 мільйона токенів це виливається в десятки мегабайт.
3. **Counter**: дублює зберігання унікальних токенів.

Потокова версія зберігає лише `Counter` (унікальні терми) та один поточний документ, тому пікова пам'ять залишається відносно сталою незалежно від розміру корпусу.
